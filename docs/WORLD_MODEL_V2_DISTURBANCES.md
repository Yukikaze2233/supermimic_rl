# 世界模型的外部扰动

当前已实现原生记录、解析调度，以及运动网络、拟合和想象循环的可选扰动路径。旧checkpoint、归一化和replay迁移尚未完成；正式世界模型仍使用原来的无外推扰配置。代码接入与训练能力分别验收。

## 原生时序与数据

沿用 `CourseRandomization` 已有配置，不另设硬件或扰动范围。PPO 当前使用的外力、力矩、速度推扰和采样间隔是训练分布，不是辨识出的硬件误差。

1. Actor 根据当前历史输出动作。
2. 原生环境在20ms区间开始时，为 NORMAL/SLOPE/STAIR 且非恢复准备的到期行施加世界系 COM 速度增量 `[dvx,dvy,dwz]`。到期但不符合条件的请求继续等待。
3. 每个5ms子步推进外力定时器，到期后重采样机身坐标系力/力矩，并保持到下一次到期。
4. 记录物理子步后，原生传感器、奖励和任务继续按原逻辑处理。复位后的新状态不能替代转移的终端状态。

`record_disturbances=true` 需要同时设置 `record_substeps=true`。默认关闭，已有快照字段和数据接口保持原样。开启后增加以下紧凑记录，每条转移共45个float：

| 字段 | 维度 | 内容 |
| --- | ---: | --- |
| `disturbance` / `end_disturbance` | 各9 | 推扰剩余时间、外力剩余时间、当前6D外力/力矩、当前episode强度 |
| `velocity_push` | 3 | 本次实际下发的 COM 世界系速度增量 |
| `external_wrench` | 4×6 | 四个子步分别使用的机身力/力矩 |

禁用的原生定时器为无穷大；记录中用0表示，是否启用由已固定的运行配置确定。到期等待的负定时器保留，不截成0。记录器不抽取随机数，不改变控制、奖励或任务，不给Actor增加输入。

## 解析组件

`DisturbanceState.advance` 复现原生定时器与随机数调用顺序，返回一次速度推扰、四个子步外力及下一状态。想象时必须使用动作前的模式与恢复准备资格，并在完整向量批上一次抽取，再供微批使用，不能在微批重抽。

想象路径使用 `advance_prepared`：每行每个20ms区间预先抽取32个均匀数，推扰占4个，四次外力更新各占7个。到期判断只选择预先准备的数，不另行抽样。因此微批、已有的地形有效行筛选和重试不会改变存活行的随机实现。它与原生调度的概率分布相同，但不承诺与原生条件抽样拥有相同的随机数序列；逐值原生核验使用上面的 `advance`。

物理状态中的线速度属于 `base_link` 原点。COM 速度跳变转换为：

```
dw_world = [0, 0, dwz]
dv_origin_world = [dvx, dvy, 0] - cross(dw_world, R @ base_com_local)
```

姿态、位置和主动关节在这个瞬时跳变中不变。`apply_velocity_push` 对姿态、COM偏置和输入增量可微。

## 网络与学习链路

运动MLP以受推后的物理状态为起点，追加四子步wrench条件，输入209→233维。仍是50Hz一次前向、四个5ms物理输出，不增加串行网络调用。拟合输出归一化使用受推后起点对应的增量标签；对外返回的增量重新转换为原始区间起点坐标，绝对物理状态不变。传感器、控制记忆和奖励继续使用原始区间历史，避免重复计入瞬时推扰。

多步拟合按步读取真实push/wrench，物理状态仍自回归预测。想象使用解析调度产生push/wrench，并按原生模式推迟不符合条件的推扰。Critic追加9维调度与当前外力状态；Actor仍为5×35原始历史及估计器，不读取未来扰动。调度状态随已有的有效行选择与轨迹边界一起推进。

单元测试覆盖：无扰动扩展后的旧模型输出保持、连续三步推扰各施加一次、拟合标签不重复学习推扰、四个wrench输入均有学习梯度、原始Actor历史不变、Critic时钟推进、同一随机实现的整批/分行目标一致，以及BPTT梯度的有限差分检查。它们验证实现，不替代受扰数据上的动力学误差和原生能力评价。

## 正式接入前剩余工作

1. 显式迁移输入层、归一化、优化器与数据接口，保留已有学习状态。新增特征不能被旧的归一化累计计数冻在错误尺度。只有已验证的无扰动旧数据可补零；旧受扰但未记录的PPO数据不能当作零扰动数据，也不能伪造历史扰动定时器。
2. 保留旧域辅助数据及独立留出行，明确旧记录能否用于想象，完成新记录路径的恢复检查。保留两个完整恢复pair，不复制在线大replay做分析。
3. 验证受扰与旧域的1/8/16/32步预测和原生学生能力；随后正式接入PPO已用的扰动分布。不能仅以新字段存在或测试通过宣布完整抗扰能力。

## 记录层已完成的原生核验

2026-11-06，在独立32环境×600步（19200转移）的PhysX采集上使用PPO已有扰动范围，记录到25个非零速度推扰、22923个非零wrench子步、24个区间内wrench切换、3个复位区间。所有区间的起止调度状态、实际推扰、四子步wrench与解析重放逐值相同；无复位区间的随机数状态也逐值相同。COM速度写入/读回误差0，解析原点速度与SDK读回的最大差2.3842e-7m/s。无终止，44项相关测试通过。未在此次自然采样中遇到到期但不符合推扰条件的行，该分支由与原生随机化类配对的单元测试覆盖。

这是记录和解析组件的一致性证据，不是受扰世界模型预测验证，也不证明策略已经掌握完整抗扰。原生审计结果保留在忽略目录 `outputs/disturbance-contract-20261106/`。
