# 35D 底盘策略的平移指令

PPO 和 SuperMimic 的网络保持 5×35 历史帧与六维底盘动作。云台继续由独立控制器控制。完整 42/45 维原始记录中的云台编码器用于上层指令坐标转换，不作为新增网络输入。

## 为什么需要转换

原生特殊平移/自旋任务把机体系 vx/vy 留为 0，平移速度、方向与云台相对 yaw 在第 35 维之后。直接截取前 35 维，会让不同平移目标具有相同的 Actor 输入。普通行走、台阶与跳跃不受这个缺失影响。

原生 `GimbalMeasurement.task_heading` 定义为底盘 yaw 加带方向/零点标定的云台编码器 yaw，区别于相机视线的水平投影。对于速度 s、云台坐标系方向 d、相对编码器角 q，送入底盘输入的水平指令是：

```
vx = s * cos(d + q)
vy = s * sin(d + q)
```

它们位于以底盘水平航向为 x 的坐标系，单位 m/s。该定义与原生水平速度奖励一致；底盘存在俯仰/横滚时仍使用水平航向，不把世界系竖直速度误混入 vx/vy。

`supermimic_rl.chassis_observation.chassis_frame` 是统一实现：每个历史帧使用该帧已经经过传感器延迟的 yaw 正余弦，无特权位姿旁路。仅特殊任务修改第 0、1 通道，其余通道和普通任务逐位保留。想象中的连续导数保留。

## 配置、旧模型与 replay

PPO/OnlineConfig 使用 `chassis_command_contract`：

- `native_first35_v1`：历史模型的直接截取语义；缺失字段按此解释。
- `gimbal_target_heading_v1`：新的目标转换，适用于 35D Actor。

新正式配置显式使用第二项。完整断点允许从第一项激活第二项，保留权重、优化器、归一化、RNG 和已有课程进度，不追加 warmup；checkpoint 保存新的配置与迁移记录。评价旧模型时按它保存的版本读取，不能用新预处理冒充原模型能力。

世界模型的 replay 继续存原始 formal45、原生目标和任务状态。投影在 Actor/估计器读入处发生，旧 replay 无需改写，动力学、任务与奖励语义也不变。教师采集按教师自己的版本执行；从旧模型初始化新模型只是复制权重，不能声称特殊目标上的动作等价。

## ONNX 与部署

导出的输入形状仍为 `[1, 5, 35]`。ONNX metadata 的 `supermimic.chassis_command_contract` 指明版本。新模型的 35D 输入应已经包含转换后的 vx/vy；只有 35D 时 `chassis_frame` 不会再次旋转它。

具备原生 42D 或 formal45 历史的调用端直接调用同一个函数。实车上在 RMCS/上层命令适配层使用一致的编码器方向、零点与时间对齐完成转换，再写入 35D 帧。网络不输出云台动作。旧 ONNX 没有该 metadata 时沿用历史输入语义，不自动改变旧模型。

## 验证

测试覆盖相反目标可区分、每帧旋转、普通输入逐位不变、倾斜底盘下与原生奖励坐标一致、有限差分梯度、PPO/世界模型/教师/原生评价的输入一致性、ONNX 数值及完整学习状态续接。原生运行检查需另外报告实际特殊任务样本数；这些一致性检查不能代替训练后的平移能力评价。

## Actor 内部的跳跃高度参考

`PPOConfig.actor_features` 和 `OnlineConfig.actor_features` 可显式启用
`{"version": "jump_reference_height_v1", "reference": {...}}`。`reference` 必须记录原生
`JumpReferenceConfig` 的全部字段，并与本次环境的参考曲线一致，不能只写部分字段后依赖默认值。
字段缺失或设为 `null` 的旧检查点保持原语义。

在 JUMP 帧内，`ActorFeatures` 用该帧已有的支撑高度、请求跳高和请求时钟，计算压缩、蹬伸、
弹道及回到支撑高度的参考，替换决策 MLP 输入中的第 3 通道（仍乘以 5）。它不读真实高度、
物理起落相位或未来状态，也不输出脚本动作。普通帧不变。原始历史和估计器始终保留支撑高度，
其余 34 个通道不变，网络参数量不变。此特征表达目标轨迹，不意味着机器人已完成跳跃。

完整 PPO 或在线学生断点可从未启用状态激活此选项；保留权重、优化器、RNG、replay 及训练计数。
激活会改变 JUMP 动作，属于带记录的策略语义变更，不能声称与旧策略等价。已有 anchor 教师
保留它自己的特征配置；新特征不暗中改写教师。世界模型仍读取原始物理转移，解析任务和奖励不变。

该变换封装在导出的 ONNX 内，`supermimic.actor_features` metadata 保存版本和完整参考参数。
调用端仍提供原始高度指令的 5×35 历史，不要再次计算并写入参考高度。水平指令仍按上文
`supermimic.chassis_command_contract` 预处理。单元测试核对原生参考曲线、PPO/学生动作、
估计器隔离、想象梯度、完整断点和 ONNX Runtime 输出；实际跳跃能力另用原生评价证明。
