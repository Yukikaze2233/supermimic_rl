# 执行链与 sim2real 边界

当前执行模型的冻结来源是 `configs/identified/20261031`。网络、课程和执行模型是不同的合同：更换为历史帧 MLP 不要求更换电机参数；旧 Transformer/MLP 的参数也不能仅因曾经用于训练就视为当前整车的辨识结果。

## 已知量的单一归属

| 环节 | 实现及来源 | 限制 |
|---|---|---|
| 轮电机 | 左右独立惯量、损耗曲线、转速力矩包络；5.5/3.5 ms 分数时延 | 时延是 command→reported RPM 的聚合量，不是 USB 单程；不再叠加旧 wheel tau/通信延迟 |
| 腿电机 | 实测局部运动库仑摩擦、160/2.5 PD、40 N·m 电机限幅 | 新摩擦数据没有辨识动态 tau、静摩擦起动或附加转动惯量 |
| 气簧 | 实测分段曲线、当前资产安装点的成对力和力矩 | 域外外推及右侧对称假设保留来源声明，不重复施加旧压力模型 |
| 传感器 | 编码器/IMU 偏置与安装变换→物理采样队列→延迟读出→策略白噪声 | requested-v2 是指定的仿真压力范围，不是完整实测噪声统计 |

轮时延在每个 5 ms 物理步的力矩边界计算。5 ms 单位脉冲的左/右响应分别为 `[0,.9,.1,0]`、`[.3,.7,0,0]`，保存延迟后零阶保持指令的区间平均冲量；没有向上取整成 10/5 ms。这不保证接触与饱和下的轨迹等同于更高物理频率。

## 轮聚合时延的 episode 随机化

factory 的 `wheel_delay_randomization=true` 启用 PPO 的可选模型参数压力分布。范围来自冻结 `wheel_model.json` 的 `uncertainty.delay`：训练方向之间的聚合时延为 3–6 ms。它不是逐 tick 抖动的实测概率分布，也不是独立 USB 时延。

每个 episode 为左右轮分别抽取 U[3,6] ms，按已有课程 smoothstep 从名义值插值到该范围。已有共享 nominal lanes（默认约 25%）保持左 5.5 / 右 3.5 ms。抽样值**替代**原聚合时延，继续用同一物理力矩队列，不串联新延迟。部分 reset 只重采并清空对应行；临时禁用电机只清队列、不重采时延。独立 RNG 不消耗现有 DR 随机流，组件 checkpoint 显式保存该 RNG。

`course-provenance.json` 的 `wheel_delay_randomization` 记录分布、范围来源和归属；每次 snapshot 的 `requested.wheel_aggregate_delay_s` 记录实际左右轮秒数。默认关闭时，旧 context、队列、receipt 和 DR 随机流不变；开启后 snapshot 的 context 明确增加两维，Actor 5×35 与原生 critic 不变。原生子步诊断仍可记录。当前 compact 世界模型使用固定时延假设，因此 `SnapshotLayout` 明确拒绝该新 context；不能把旧 WM 当作已覆盖这种域随机化。

## PhysX 轮静摩擦

factory 的 `identified_friction_mode="native_floor"` 启用已存在的模型分工：PhysX 承担轮静摩擦和动摩擦基值，软件只计算剩余运动摩擦。默认 `software_dynamic` 保留旧运行语义；Kamino 不支持这对独立系数，不能直接启用。

轮静峰名义值为左 0.19、右 0.375 N·m，来自原模型的观测区间 0.15–0.23、0.30–0.45 N·m，**并非精确辨识值**。动摩擦基值约为 0.04105/0.13317 N·m。腿部没有对应静峰测量，不借用轮参数或旧闭环拟合值。

工厂从 `robot.root_view.get_dof_friction_properties()` 按后端关节名读回全部环境的六根主动轴，验证 static/dynamic/viscous 三列。`native-setup-readback.json` 保存请求值、实际极值、单位、数据 SHA 和辨识边界；`course-provenance.json` 记录启用方式。参数读回与短步进通过，只证明接线生效，不等于整机静止漂移或实车起动能力已通过。

## 同一编码器标定

runtime 的 `requested_randomization.shared_encoder_bias=true` 对齐 RMCS 中 Actor 与主机 PD 读取同一 `q_` 的关系。两者共享四个腿关节的标定零偏，保留原有 ±0.004 rad 压力范围；轮位置偏置仍为零。独立白噪声、延迟队列和采样时刻不因此共享。

实现仍消费旧版两次偏置抽样，只让策略偏置取 PD 偏置的值，其余域随机化和后续 reset 的随机流不改变。context 中两个偏置槽保留，Actor 的 5×35 接口、估计器和动作维度不变。旧独立偏置模式仍可复现，不能将它称为实车存在两套独立编码器的证据。

requested-v2 原配置的一个策略 tick 为 10 ms，迁入当前 50 Hz Actor 后仍保留 0/10 ms 观测延迟；不能按当前策略周期误改为 0/20 ms。25% nominal 环境叠加随机环境的二选一延迟，使全体约 37.5% 带有额外 10 ms 延迟。

## 尚待补齐的动态证据

旧腿 tau 约 3.86/4.41 ms 来自固定旧 CAD、气簧、标定和 1 kHz 主机 PD 条件下，与惯量、阻尼、摩擦的联合拟合；原报告说明它可能吸收反馈效应。它不是独立电流环时间常数，不能摘取后与新摩擦、USB 延迟直接相加。

现有 USB-HS 回环摘要约 80 µs 中位 RTT、84 µs 的 p99；未分离上下行，也不覆盖完整实车负载的总线、调度和电机响应。旧训练 U(0.1,2) ms 或 U(0.1,5) ms 是工程覆盖范围，不能冒称该回环实测分布。

需要当前部署版本下带命令和反馈时间戳的腿部瞬态记录。固定当前机械、气簧和已知摩擦后，先核时间轴与可辨识性，再拟合最少的残余动态参数；主动执行器响应不能作用到被动气簧/摩擦。已有世界模型回放的物理合同也不会因 PPO 切换执行模式而自动更新。
